# Development Workflow

## Local workflow

1. Install dependencies for the API and web application.
2. Configure local environment variables from the examples.
3. Start the backend and frontend.
4. Make focused changes.
5. Run targeted tests first, then the broader checks.
6. Review the diff before committing.

## Git workflow

Prefer small, descriptive commits that explain one logical change. Keep generated artifacts, local databases, credentials, and uploaded documents out of version control.

## Review workflow

Before merging, verify the affected user flow and document any intentional limitations.
