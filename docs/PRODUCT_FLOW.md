# Product Flow

1. User signs in.
2. User creates or opens a resume project.
3. The LaTeX source is edited in the browser.
4. User provides a job description PDF.
5. The backend extracts and structures job-description information.
6. ATS analysis identifies relevant requirements.
7. Tailoring produces a separate proposed resume version.
8. User reviews the changes before using the version.
9. The resume can be compiled to PDF.
10. A cover letter can be generated from the selected resume and job description.

The original source remains available for comparison and recovery.
