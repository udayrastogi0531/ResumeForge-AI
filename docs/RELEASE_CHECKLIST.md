# Release Checklist

## Application

- [ ] Authentication flow verified.
- [ ] Resume creation and versioning verified.
- [ ] JD PDF upload/extraction verified.
- [ ] Tailoring result reviewed for factual accuracy.
- [ ] ATS analysis verified.
- [ ] LaTeX compilation verified.
- [ ] Cover-letter generation verified.
- [ ] Original resume remains unchanged.

## Engineering

- [ ] Tests pass.
- [ ] Frontend lint passes.
- [ ] Production build passes.
- [ ] Secrets are excluded from Git.
- [ ] Deployment environment variables are configured.
- [ ] LaTeX execution limits are enabled for public deployments.

## AI providers

- [ ] Configured provider is reachable.
- [ ] Failure/fallback behavior is understood.
- [ ] API credentials are stored outside source control.
