# AI Safety and Truthfulness

ResumeForge AI is designed to tailor resumes without inventing candidate information.

## Rules

The tailoring workflow should:

- Reuse facts already present in the source resume.
- Align wording with the job description when the source resume supports it.
- Avoid fabricating skills, employers, education, certifications, projects, dates, or performance metrics.
- Preserve the original resume version so the user can review proposed changes.
- Treat AI-generated validation as a review signal, not as proof that every claim is true.

## User review

The final responsibility for factual accuracy remains with the resume owner. Users should inspect the generated diff before submitting an application.
