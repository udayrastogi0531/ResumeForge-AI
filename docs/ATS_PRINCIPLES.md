# ATS Analysis Principles

ATS analysis should help users understand alignment between a resume and a target job description.

Useful signals include:

- Relevant skills and keywords
- Role-specific terminology
- Missing or weakly represented requirements
- Resume structure and readability

An ATS score is a heuristic signal, not a guarantee of recruiter or applicant-tracking-system behavior. Users should review the underlying findings rather than treating a single number as definitive.
